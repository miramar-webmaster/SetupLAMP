This is the help file for the SetupLAMP script suite.

REQUIREMENTS:
=============

You will need a bare Ubuntu 24.04+ install in a virtual machine.

You will need to have Git installed, and a PGP key set up for your Github account.

PROCEDURE:
===========

Using Git, clone this repository to your Linux desktop.

git clone git@github.com:miramar-webmaster/SetupLAMP.git

go into the SetupLAMP directory.

Run chmod +x *.sh, just in case.

Run ./setuplamp.sh and follow the prompts.

You will have the option to install a bare LAMP server, without setting up the College website.

If you don't choose that option, you will have the option for one of three environments:

dev	Development
stage	Staging
prod	An emergency production site
